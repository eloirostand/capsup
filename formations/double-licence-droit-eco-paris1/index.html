En bref

Procédure d’admission

Admission uniquement en 1re année, sur dossier via Parcoursup (dossier dématérialisé), pour les bacheliers comme pour les étudiants en réorientation ; pas d'entrée en cours de cursus. Session 2025 : 2 718 candidatures pour 60 places (FAQ de l'École de droit de la Sorbonne). L'étudiant suit 4 séances de TD par semaine : 2 en droit, 2 en économie.

Vœu Parcoursup

Vœu simple : compte pour 1 vœu parmi les 10. Sauf exception (PASS Île-de-France), il n'y a pas de vœu multiple pour les licences : la même formation dans un autre établissement est un autre vœu.

Conditions d’admissibilité

  • Baccalauréat ; admission sur dossier via Parcoursup.
  • Test de langue : aucun exigé dans les sources consultées.
  • Moyenne ou mention minimale : aucun seuil chiffré publié (le dossier est classé).

Admissions parallèles

Écoles de commerce (AST) et Sciences Po (master) envisageables après L2/L3, comme pour les licences simples
